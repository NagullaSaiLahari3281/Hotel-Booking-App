# 🏨 Hotel Booking Web App

## 📖 Project Description
This is an interactive hotel booking web application where users can select check-in and check-out dates, 
choose room types, and book rooms easily. The app includes real-time form validation and user-friendly popup messages for success and error handling.

---

## ✨ Features
- 📅 Check-in & Check-out date selection
- 🏨 Room options (Deluxe, Suite, Standard)
- 📝 Booking form (Name, Email, Phone, Special Request)
- ⚡ Real-time validation for inputs
- ❌ Error popup for invalid inputs
- ✅ Success popup with booking details
- 📱 Fully responsive design

---

## 📱 Responsive Design
- 💻 Desktop → 3-column layout  
- 📱 Tablet → 2-column layout  
- 📲 Mobile → 1-column layout
